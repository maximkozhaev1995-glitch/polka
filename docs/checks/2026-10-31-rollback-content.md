# Дополнение к дневнику: проверка содержимого после отката

Дата: 31.10.2026. Связанный документ: [дневник проекта](../PROJECT_JOURNAL.md).

Ранее в дневнике подтверждались 15 успешных SQL-проверок, количества строк и отсутствие тестовых записей. Теперь выполнена дополнительная проверка содержимого восьми таблиц тестового Supabase `mixora-b5-test`.

## Результат

Контрольные отпечатки данных до и после испытания совпали во всех восьми таблицах. Это проверка не только количества записей, но и их содержимого.

| Таблица | Строк до и после | MD5 до = MD5 после |
|---|---:|---|
| public.venues | 2 | 3f33430aa4f3a4ea5861c4f24538fb93 |
| public.users | 4 | e657889f98d0adf98c35ca7279c1e070 |
| public.flavors | 26 | 3bdf63f3bd2586c2ca20063a0fea8020 |
| public.stock | 2 | b76f4471bb252d011121527697468021 |
| public.moves | 0 | d751713988987e9331980363e24189ce |
| public.flavor_strengths | 0 | d751713988987e9331980363e24189ce |
| public.flavor_packs | 0 | d751713988987e9331980363e24189ce |
| mixora_private.stock_requests | 0 | d751713988987e9331980363e24189ce |

Формула одинакового представления данных для сравнения:

```sql
md5(coalesce(
  jsonb_agg(to_jsonb(t) order by to_jsonb(t)::text),
  '[]'::jsonb
)::text)
```

Первый повторный запрос отсортировал users по числовому tg_id и вернул другой отпечаток: `3d249f46d762a1cf167ec36f1e224e78`. Проверка с сортировкой по полной JSON-строке вернула исходный `e657889f98d0adf98c35ca7279c1e070`. Причина расхождения — порядок строк в сравнении, а не обнаруженная потеря данных. Временных пользователей с меткой этого теста осталось 0. Для сверки содержимое таблиц не изменяли.

## Границы вывода

- Подтверждено совпадение содержимого восьми перечисленных таблиц по контрольным отпечаткам. MD5 используется здесь для проверки случайных различий, а не как криптографическая гарантия против намеренной подмены.
- Не проверены все остальные таблицы, технические логи и счётчики последовательностей.
- Сверка не заменяет вход через настоящий Telegram, запросы из браузера, одновременные сессии или испытание ИИ по реальному фото.
- Проверку выполнил главный инженер через инструмент Supabase. Это не независимое ревью другим агентом.
- Рабочая база и код приложения не менялись. Этот документ сохраняется только в отдельной ветке аудита.
