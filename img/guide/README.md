# Скриншоты для раздела «Как пользоваться»

Файл кладётся сюда под точным именем — гайд подхватывает его сам, без правок кода.
Пока файла нет, в разделе показывается пунктирная заглушка с подписью, какой экран нужен.
Текущие скриншоты сняты с самого приложения на тестовых данных (не реальный склад), ширина телефона 390 px.
`03-foto.png` не нужен: раздел «Фото банок» в рабочем приложении скрыт.

Формат: PNG, вертикальный скриншот телефона из Telegram (ширина ~1080 px, показывается до 280 px).
