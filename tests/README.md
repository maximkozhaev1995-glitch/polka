# Локальные регрессии без сети и production

Из корня репозитория:

```
node tests/matching.cjs
node tests/actions.cjs
npm ci
npm test
```

Первые два теста требуют только Node 18+. Полный набор B5 требует Node 22+ и закреплённые devDependencies из lockfile. Ключи и доступ к рабочей базе не нужны.
Matching исполняет реальные функции из src/stoika.html и использует случаи audit/ai-stand/match.mjs.
Actions исполняет реальные функции предложений/команд/диалога из исходника; база, модель и DOM — заглушки. Это не браузерный тест и не настоящий Claude API.
Браузерный стенд и инструкции: audit/ai-stand/README.md.

`stock-rpc.mjs` исполняет миграцию и проверки в PGlite на тестовой схеме. Это настоящий SQL, но одна сессия; параллельные подключения и совместимость с полной схемой production пока не проверены.
`stock-client.cjs` исполняет реальный адаптер RPC и обработчик подтверждения с заглушками сети/DOM, проверяет потерянный ответ, повтор и восстановление.
`syntax.cjs` проверяет синтаксис встроенных скриптов и адаптера. Перед полным набором пересоберите index.html через `build_app.py`.
Ограничения и требуемые разрешения: `MIXORA_B5_RESULTS.md`.
