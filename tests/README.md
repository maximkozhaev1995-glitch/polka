# Локальные регрессии без сети и production

Из корня репозитория:

```
node tests/matching.cjs
node tests/actions.cjs
npm ci
npm test
```

Первые два теста требуют только Node 18+. Полный набор B5 требует Node 22+ и закреплённые devDependencies из lockfile. Ключи и доступ к рабочей базе не нужны.
Matching исполняет реальные функции из src/stoika.html и использует случаи tests/fixtures/matching-cases.json.
Actions исполняет реальные функции предложений/команд/диалога из исходника; база, модель и DOM — заглушки. Это не браузерный тест и не настоящий Claude API.
Браузерный прогон: tests/stock-browser.mjs, команды ниже.

`stock-rpc.mjs` исполняет миграцию и проверки в PGlite на тестовой схеме. Это настоящий SQL, но одна сессия; параллельные подключения и совместимость с полной схемой production пока не проверены.
`stock-client.cjs` исполняет реальный адаптер RPC и обработчик подтверждения с заглушками сети/DOM, проверяет потерянный ответ, повтор и восстановление.
`syntax.cjs` проверяет синтаксис встроенных скриптов и адаптера. Перед полным набором пересоберите index.html через `build_app.py`.
Ограничения и требуемые разрешения: `MIXORA_B5_RESULTS.md`.

Дополнительный локальный прогон: `npm run test:integration` (PostgreSQL 17 + несколько подключений + установленный Chrome). Ничего не подключается к рабочей Supabase; исходная схема восстановлена только из метаданных. PostgreSQL запускается на 127.0.0.1 с временным паролем, без службы и новых системных пользователей. Тестовые кластеры остаются в игнорируемой `.local-tests/` для диагностики, сервер останавливается после тестов.

Claude запускается **только после отдельного разрешения** через `RUN_CLAUDE=1` при запуске `tests/stock-browser.mjs`. `MIXORA_TEST_CLAUDE_MODEL=claude-sonnet-5-5` выбирает проверенный доступный вариант; `RUN_CLAUDE_CASES` ограничивает список сценариев. Только настроенные `ANTHROPIC_*` переменные используются на сервере, в браузер/отчёт они не попадают. Счётчик всех внешних попыток (включая SDK-повторы) хранится в `.local-tests/claude-b5-budget.json` и ограничен 75; не удалять/сбрасывать его в рамках одного разрешённого прогона. На 503/сетевом сбое ограничитель останавливает дальнейшие внешние попытки текущего процесса. Это исполнение исходника Edge Function через локальный Node-адаптер, не деплой и не проверка шлюза Supabase/Deno.

## Повторный аудит PR #77

Текущий полный набор: Node 24+, `npm ci --ignore-scripts`, `python3 build_app.py`, `npm test`.
`stock-rpc.mjs` сохраняет проверки исторической миграции #74 **до** изменения прав; `uniform-access.mjs` проверяет окончательные одинаковые права обеих legacy ролей после всех миграций.

В Linux без ICU 60 используйте одноразовый Docker PostgreSQL и установленный Chromium:

```
MIXORA_TEST_DOCKER=1 MIXORA_CHROMIUM=/usr/bin/chromium npm run test:integration
```

Создаются только тестовые контейнеры с loopback-портами; после тестов они останавливаются. `RUN_CLAUDE` не задавать: реальная модель не входит в этот прогон. Метаданные, совместимость #73–75 и оставшиеся риски описаны в `audit/pr77/RESULTS.md`.
