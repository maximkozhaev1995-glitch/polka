# Полка

Склад и табачная карта для кальянной, с ИИ. Telegram Mini App. Бот: [@PolkaHookahbot](https://t.me/PolkaHookahbot) (Mini App для сотрудников: короткое имя `PolkaSklad`).

## Как устроено

- **Сайт**: статика на GitHub Pages (ветка `main`, корень). Без сборки и фреймворков, чистый HTML и JS.
  - `index.html`: приложение для сотрудников (склад, стойка, заказ, журнал, альбом миксов, команда, ассистент, инвентаризация, граммовка, крепость, пожелания гостей). Собирается скриптом `build_app.py` из `src/stoika.html` и `app/`.
  - `karta/index.html`: гостевая карта. Собирается `tools/build_karta.py` из `karta/template.html` (нужен `SUPABASE_ACCESS_TOKEN` в окружении). Каталог вкусов вшит, наличие и миксы карта берёт из базы при открытии. GitHub Pages кэширует страницу до ~10 минут.
- **База и серверная часть**: Supabase (PostgreSQL).
  - `supabase/migrations_*.sql`: схема, права по ролям (RLS), триггеры и SECURITY DEFINER-функции.
  - `supabase/functions/tg-auth`: вход через Telegram. Проверяет подпись `initData`, выдаёт JWT. Гости без входа читают только представления `public_stock`/`public_mixes` и напрямую таблицы `wishes`/`guest_mixes` (по анонимному ключу, ограниченно политиками RLS).
  - `supabase/functions/ai`: прокси к ассистенту. Сейчас работает на бесплатном Gemini (перебор моделей `gemini-3.5-flash` → `flash-latest` → `flash-lite` при перегрузе/лимите, клиент сам повторяет запрос с паузой); код поддерживает и Claude API (`ANTHROPIC_API_KEY`), переключение через секрет `AI_PROVIDER`. Лимит — 75 запросов в сутки на пользователя.
- **Слой данных в приложении**: `app/shim.js`. Приложение написано под интерфейс коллекций (`collection`, `doc`, `onSnapshot`), `shim.js` реализует его поверх REST Supabase: опрос каждые 6 секунд и обновление после каждой записи.

## Доступ сотрудников

Все авторизованные сотрудники одного заведения имеют одинаковый полный доступ, включая журнал и отмену операций. Роль PostgREST `authenticated` обозначает проверенный вход, а не должность. Исторические `users.role/perms` и `invites.role` остаются в схеме для совместимости и не определяют полномочия. Переключателя Мастер/Управляющий и назначения индивидуальных разрешений нет.

Склад и журнал движений меняются одной транзакцией через `apply_stock`: UUID защищает от повторов, revision — от перезаписи чужих изменений, отмена создаёт компенсационное движение. Исторические записи без operation_id и уже перекрытые изменения автоматически не отменяются.

Draft PR #77 содержит миграции в `supabase/migrations/`, обновления клиента и Edge Functions. Их согласованный выпуск требует отдельного разрешения; новые миграции не применялись к production. Проверки и оставшиеся риски: [отчёт повторного аудита](audit/pr77/RESULTS.md).

## Пожелания гостей и миксы по QR

- **Пожелания**: гость в карте отмечает вкус, которого нет на стойке («Хочу, чтобы был») или пишет свой. Запись уходит в таблицу `wishes` (анонимная вставка, не больше 10 в сутки с одного устройства). Управляющий видит их в приложении и переносит в заказ.
- **Микс по QR**: гость в карте («Избранное» → «Показать QR мастеру») получает QR и код, которые кодируют ссылку `https://t.me/PolkaHookahbot/PolkaSklad?startapp=guest_<код>`. Мастер:
  - сканирует QR **любой камерой** телефона — Telegram откроет приложение и сразу форму микса (код подставляется автоматически через `start_param`);
  - либо в приложении, во вкладке «Альбом миксов» → «Внести микс гостю по QR», сканирует через встроенный сканер Telegram или вводит код вручную.
  - Запись уходит в таблицу `guest_mixes`; гость забирает её опросом раз в 4 секунды, пока открыт экран QR, и получает её в «Моё избранное». Отметка «забрал» идёт через функцию `claim_guest_mix` (SECURITY DEFINER) — прямой `UPDATE` от анонимной роли для этой таблицы не работает (на этом проекте воспроизведено: сочетание SELECT+UPDATE policy для одной роли ломает RLS).

## Секреты

В репозитории нет секретов. Публичный ключ `anon` в `app/config.js` предназначен для браузера, доступ ограничен правилами RLS. Токен бота, ключ ИИ и ключ сервиса лежат только в секретах Supabase.
