# Полка

Склад и табачная карта для кальянной, с ИИ. Telegram Mini App. Бот: [@PolkaHookahbot](https://t.me/PolkaHookahbot).

## Как устроено

- **Сайт**: статика на GitHub Pages (ветка `main`, корень). Без сборки и фреймворков, чистый HTML и JS.
  - `index.html`: приложение для сотрудников (склад, стойка, заказ, журнал, альбом миксов, команда, ассистент). Собирается скриптом `build_app.py` из `src/stoika.html` и `app/`.
  - `karta/index.html`: гостевая карта. Собирается `tools/build_karta.py` из `karta/template.html`. Каталог вкусов вшит, наличие и миксы карта берёт из базы при открытии.
- **База и серверная часть**: Supabase (PostgreSQL).
  - `supabase/migrations_*.sql`: схема, права по ролям (RLS), триггер, ограничивающий мастера.
  - `supabase/functions/tg-auth`: вход через Telegram. Проверяет подпись `initData`, выдаёт JWT. Гости без входа читают только представления `public_stock` и `public_mixes`.
  - `supabase/functions/ai`: прокси к Claude API с лимитом запросов. Ключ ИИ хранится в секретах Supabase.
- **Слой данных в приложении**: `app/shim.js`. Приложение написано под интерфейс коллекций (`collection`, `doc`, `onSnapshot`), `shim.js` реализует его поверх REST Supabase: опрос каждые 6 секунд и обновление после каждой записи.

## Роли

- `manager` видит и меняет всё.
- `master` по умолчанию только добавляет вкус в стоп-лист. Остальное по списку прав (`perms`): `take`, `add`, `offbar`, `slow`, `unstop`. Права проверяются и в интерфейсе, и в триггере `enforce_master_stock`.

## Секреты

В репозитории нет секретов. Публичный ключ `anon` в `app/config.js` предназначен для браузера, доступ ограничен правилами RLS. Токен бота, ключ ИИ и ключ сервиса лежат только в секретах Supabase.
